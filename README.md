# Full Stack

Coursework for the Full Stack Lab — BS Computer Science, Air University, Islamabad.

Every project here is built with **plain HTML5 and CSS3 only**: no frameworks, no build
step, no JavaScript. Open any `index.html` directly in a browser.

## Lab 2

| # | Project | What it covers |
|---|---------|----------------|
| [Task - 1](Lab%202/Task%20-%201) | Starter page | Base HTML/CSS structure |
| [Task - 2](Lab%202/Task%20-%202) | Facebook home page clone | Fixed header, sticky rails, story row, feed cards, status posts. All images are locally generated dummy SVGs. |
| [Task - 3](Lab%202/Task%20-%203) | Personal portfolio | Dark developer theme, code-editor card, skills grid, project cards, CSS-only timeline |
| [Task - 4](Lab%202/Task%20-%204) | Cyber-deck terminal UI | CRT scanlines, phosphor palette switching, ASCII meters and controls — all in CSS |
| [Task - 5](Lab%202/Task%20-%205) | IEEE conference paper template | Two-column US Letter layout rebuilt from the original `.docx` style sheet; prints to real pages |

## Running

```bash
git clone https://github.com/Dev-EhtishamUlHaq/Full-Stack-Web-Development.git
cd "Full-Stack-Web-Development/Lab 2/Task - 3"
# then open index.html in a browser
```

## Notes

- Task 2 reproduces Facebook's layout as a CSS exercise; it is not affiliated with Meta
  and is not intended for deployment under that branding.
- Task 4 ships a `CRT_FX` toggle and honours `prefers-reduced-motion` for readability.
- Task 5 matches the IEEE template's real metrics (24pt title, 9pt authors, 10pt body,
  two columns with an 18pt gutter on US Letter).
